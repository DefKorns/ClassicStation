# ClassicStation v0.1.0-alpha.6

Sixth alpha of ClassicStation, the EmulationStation port for the NES and SNES Classic with hakchi. It is still meant for testers: expect rough edges.

> [!CAUTION]
> **Needs an SD card or USB stick; do not install on the NAND.** The themes, covers and downloaded images are too large for the console's internal storage, so they are kept on the card, and only the program and its scripts stay on the NAND. It has only been tested with the firmware swap method, on a NES (USA), a SNES (USA) and a Famicom.

The hmod keeps its id, so it updates in place.

Needs a RetroArch hmod for games that run on RetroArch: **RetroArch (S)NESCE v1.22.2-beta.13 or newer**, or the RetroArch 1.9.10 from KMFDManic. The suspend point screenshot fix for RetroArch games is in the RetroArch (S)NESCE hmod, so update it too.

## What's new

- **Eight languages.** English, German, Spanish, French, Italian, Dutch, Portuguese (Portugal) and Russian. A Language option in Tools, Behaviour switches the menus, dialogs, buttons, help hints and the Wi-Fi messages to the chosen language and asks to restart. The controller setup, the hidden developer menu and game titles stay in English.
- **A rebuilt network menu.** The Network tab has Current network (disconnect or connect, back up and forget, with the IP address under the name), Connect to network, and Saved networks with a Restore networks list. Backups go to the SD card, one folder per network, in the same place and format as the Options Menu, so backups from either are listed.
- **Romaji titles on Japanese consoles.** A Romaji titles switch in the Library tab shows the original games with romaji names instead of kana and kanji. It only appears on Japanese consoles, and turning it on or off rebuilds the library and restarts ClassicStation.
- **Suspend points.** Saving over a slot that already has a suspend point now asks first, and the screenshot of suspend points saved from RetroArch games shows in the list.
- **Choice dialogs open on No.** Every yes or no question starts with No selected, so a stray A press cannot overwrite or delete anything.
- **The HUD on the systems screen.** The NAND, SD card and swap indicators, and the overclock icon, now show on the home screen as well as in the game lists.
- **Systems screen counts.** The favorites count is hidden when it is zero.
- **Power saver on by default** on a fresh install (the default mode, 10 seconds without input). On a Famicom the idle CPU on the systems screen goes from about 27% to about 1% of one core. Existing settings are kept; change it in Behaviour.
- **Credits** for the Hakchi Memory Booster (swap file) and Easy OC (overclock) ideas.
- **N64 cores.** Games that run on an N64 core (mupen64plus, parallel_n64, GLupen64, ludicrousn64) no longer try to write a save state when you quit, since those cores do not support it.
- **Long game codes** on the home screen cards no longer wrap: the code box is wider.
- **A rewritten README**, with the theme, build and port notes moved to their own files.
- **Cleanup.** The unreachable game delete button was removed from the metadata editor.

## Known issues

- No video playback.
- The first boot builds the library, which takes a while on large collections.
- The interface slows down while the scraper runs.
- Games need the RetroArch hmod with its cores installed.
- Kid mode shows only the games you marked, so mark some before switching to it.
- Turning Romaji titles on or off shows the menu again for a moment before the restart screen.
- On the NES, the CRT filter blurs the picture on the CPU before it reaches the options, so Sharp and Pixel only reduce part of the softness. For a sharp picture with scanlines, use 4:3 or pixel perfect with a scanline step.
- TheGamesDB uses a shared default key with a monthly limit that can run out; enter your own key in Network, Scraper, TheGamesDB API key.
- A DualShock 4 works in ClassicStation but not yet inside games.
- Arcade with the KMFD cores: `km_mame2003_plus` runs but heavy games like Mortal Kombat are CPU bound and the sound crackles, and `km_mame2000` crashes when the game starts (the core, not ClassicStation).

## Install or update

1. Put an SD card or USB stick with a `hakchi` folder in the console; the install needs it for the themes.
2. Download `emulationstation_classicmini.hmod`. It is not in my hakchi mod repository yet, so for now it is installed by hand. Put it in hakchi's `user_mods` folder, select **ClassicStation** under Frontend and sync. Updating keeps the settings, favorites and the theme files you changed.
3. If hakchi reports the install as done but ClassicStation does not start, read hakchi's log: without the card or stick the install stops and hakchi still marks the module as installed. Remove it with "Remove modules" and try again.

To report a problem, send `/var/lib/hakchi/emulationstation/home/.emulationstation/es_log.txt` and, after a crash, `/var/lib/hakchi/emulationstation/crash.log`.
