# ClassicStation v0.1.0-alpha.4

Fourth alpha of ClassicStation, the EmulationStation port for the NES and SNES Classic with hakchi. It is still meant for testers: expect rough edges.

The hmod keeps its id, so it updates in place.

Needs the RetroArch (S)NESCE hmod **v1.22.2-beta.13 or newer** for games that run on RetroArch.

## What's new

- **Video options for the SNES.** The Video Mode and Bezel menu has a Filter list (Nearest, Linear, Horizontal linear, Sharp, Composite and Phosphor) and five scanline steps (off, original, soft, medium, strong), with a preview for each. Composite adds a chroma blur and Phosphor adds an RGB mask on top of it. They work on the `canoe` builds from EUR and USA firmware 2.0.13 and 2.0.14 and JP (shvc) 2.0.14; on older builds only the scanline steps work, and on any other build the options show as plain scanlines.
- **Video options for the NES.** The scanline steps now work on the NES too, and the video mode (4:3, pixel perfect, CRT filter) uses the console's own display filters. In CRT filter mode there are three extra options: CRT smoothing (stock, soft, sharp, pixel), the scanline strength, and the CRT size (4:3 or pixel perfect). They only appear on the NES, and the Bezel row is hidden when there are no bezels.
- **Suspend points shared with the console menu (NES).** The ES now saves and reads suspend points in the console's own format, so a point saved in ClassicStation shows up in the stock menu and the other way round. Saves use the stock `save.sram` name; if a game had a save from an older version, it is copied once.
- **Autofire.** The controller autofire is off while you move around ClassicStation and back on inside games.
- **Collections.** Favorites and Other have their own logos and backgrounds, and the Mega Drive wrapper (`m2engage`) is listed under Mega Drive.
- **Developer entry in Help.** Debug mode and an opt-in video debug log, written to `/media/data/log/crtfx/journal.log`.
- **Leaving for the stock menu.** Quitting ClassicStation to the console menu shows a short splash, and opening a folder in the stock menu afterwards no longer starts ClassicStation again.

## Known issues

- No video playback.
- The first boot builds the library, which takes a while on large collections.
- The interface slows down while the scraper runs.
- The NES Classic and the Famicom firmware have been tested much less than the SNES Classic.
- Games need the RetroArch hmod with its cores installed.
- Kid mode shows only the games you marked, so mark some before switching to it.
- The Composite and Phosphor filters and the scanline steps for the SNES need one of the `canoe` builds listed above.
- On the NES, the CRT filter blurs the picture on the CPU before it reaches the options, so Sharp and Pixel only reduce part of the softness. For a sharp picture with scanlines, use 4:3 or pixel perfect with a scanline step.
- The splash shown when leaving for the stock menu has a faint rectangle around the icon.
- NES games on RetroArch with the Nestopia core can look blurry in pixel perfect mode: the core enables its NTSC filter. Set "NTSC Filter" to off in the core options (or use FCEUmm).
- TheGamesDB uses a shared default key with a monthly limit that can run out; enter your own key in Network, Scraper, TheGamesDB API key.
- A DualShock 4 works in ClassicStation but not yet inside games.
- Arcade with the KMFD cores: `km_mame2003_plus` runs but heavy games like Mortal Kombat are CPU bound and the sound crackles, and `km_mame2000` crashes when the game starts (the core, not ClassicStation).

## Install or update

1. Put an SD card or USB stick with a `hakchi` folder in the console; the install needs it for the default theme.
2. Download `emulationstation_classicmini.hmod`, put it in hakchi's `user_mods` folder, select **ClassicStation** under Frontend and sync. Updating keeps the settings, favorites and the theme files you changed.
3. If hakchi reports the install as done but ClassicStation does not start, read hakchi's log: without the card or stick the install stops and hakchi still marks the module as installed. Remove it with "Remove modules" and try again.

To report a problem, send `/var/lib/hakchi/emulationstation/home/.emulationstation/es_log.txt` and, after a crash, `/var/lib/hakchi/emulationstation/crash.log`.
