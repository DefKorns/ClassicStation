# ClassicStation v0.1.0-alpha.5

Fifth alpha of ClassicStation, the EmulationStation port for the NES and SNES Classic with hakchi. It is still meant for testers: expect rough edges.

> [!CAUTION]
> **Do not install on the NAND.** It has only been tested with the firmware swap method, on a NES (USA) and a SNES (EUR) console.

The hmod keeps its id, so it updates in place.

Needs a RetroArch hmod for games that run on RetroArch: **RetroArch (S)NESCE v1.22.2-beta.13 or newer**, or the RetroArch 1.9.10 from KMFDManic.

## What's new

- **The classicstation theme.** Two themes now ship with the hmod: simple and classicstation. The classicstation theme looks like the console's own home menu and is generated on the console from the artwork of the installed firmware (NES, Famicom, SNES, Super Famicom and the Shonen Jump firmware). On the first boot ES switches to it once; you can go back to simple in Appearance.
- **Original games.** A collection with the console's built-in games, with card images for each console, and the system screen shows the game counts.
- **Suspend points.** The list slides in over the home screen, with a floating card that shows the screenshot, ring and play time. Y saves on the floating card, and floating resume works on canoe and RetroArch.
- **Demo mode.** After a minute idle, Mario and Luigi run across the screen (SNES layouts).
- **A new menu.** Six tabs: Display, Sound, Library, Network, Tools and System, with themed icons and a highlight that moves between the cards and the menu bar. The header rises with the bar and the cursor flies between the card and its icon, as in the stock menu.
- **Appearance and Behaviour pages.** The appearance settings are grouped, the behaviour ones (UI mode, power saver) are apart, and the performance options live in Developer.
- **Power saver.** Disabled, default, enhanced and instant modes; any input wakes the console.
- **Slideshow screensaver folders on the SD card**, so they survive a reinstall.
- **Faster Developer menu**, opened with a single call and a busy indicator.
- **Fixes.** The grid highlight is kept per view and released when the view hides, the game code shows after a fast scroll, the filter returns to Nearest when Pixel Perfect cannot use Sharp, the NES bar logo appears on the SNES USA layout, and the menu frame no longer has dark corners.

## Known issues

- No video playback.
- The first boot builds the library, which takes a while on large collections.
- The interface slows down while the scraper runs.
- Games need the RetroArch hmod with its cores installed.
- Kid mode shows only the games you marked, so mark some before switching to it.
- On the NES, the CRT filter blurs the picture on the CPU before it reaches the options, so Sharp and Pixel only reduce part of the softness. For a sharp picture with scanlines, use 4:3 or pixel perfect with a scanline step.
- TheGamesDB uses a shared default key with a monthly limit that can run out; enter your own key in Network, Scraper, TheGamesDB API key.
- A DualShock 4 works in ClassicStation but not yet inside games.
- Arcade with the KMFD cores: `km_mame2003_plus` runs but heavy games like Mortal Kombat are CPU bound and the sound crackles, and `km_mame2000` crashes when the game starts (the core, not ClassicStation).

## Install or update

1. Put an SD card or USB stick with a `hakchi` folder in the console; the install needs it for the themes.
2. Download `emulationstation_classicmini.hmod`. It is not in my hakchi mod repository yet, so for now it is installed by hand. Put it in hakchi's `user_mods` folder, select **ClassicStation** under Frontend and sync. Updating keeps the settings, favorites and the theme files you changed.
3. If hakchi reports the install as done but ClassicStation does not start, read hakchi's log: without the card or stick the install stops and hakchi still marks the module as installed. Remove it with "Remove modules" and try again.

To report a problem, send `/var/lib/hakchi/emulationstation/home/.emulationstation/es_log.txt` and, after a crash, `/var/lib/hakchi/emulationstation/crash.log`.
