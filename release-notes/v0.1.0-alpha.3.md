# ClassicStation v0.1.0-alpha.3

Third alpha of ClassicStation, the EmulationStation port for the NES and SNES Classic with hakchi. It is still meant for testers: expect rough edges.

The port is now called **ClassicStation**. It is a fork of RetroPie's EmulationStation, trimmed for the minis, and the hmod keeps its id, so it updates in place.

Needs the RetroArch (S)NESCE hmod **v1.22.2-beta.13 or newer** for games that run on RetroArch.

## What's new

- **Favorites with Y again.** In the games view, Y adds or removes the favorite, as in the original EmulationStation. Sorting is only in the Select menu now (Sort games by). The NES pad has no X or Y, so everything it needs is in the Select menu.
- **Kid mode.** Select, Add to kid games marks a game, and UI Settings has the UI mode setting back (Full or Kid). In Kid mode only the marked games show and most menus are hidden. To leave it, enter the code shown when you switch to it (up, up, down, down, left, right, left, right, B, A). Kiosk mode is gone.
- **Return to ClassicStation tile.** New emblem and complete fields, and a fix for the description (hakchi showed `Text =` as its first line). Remove the old tile in hakchi and add the new package from the `hakchi-app` folder.
- **Smaller code base.** Everything the minis cannot use was removed: the desktop GL renderers, the Raspberry Pi, OMX and Vero4K code, the Windows files, and the MAME name tables (the names come from hakchi). Nothing changes on the console.

## Known issues

- No video playback.
- The first boot builds the library, which takes a while on large collections.
- The interface slows down while the scraper runs.
- The NES Classic and the Famicom firmware have been tested much less than the SNES Classic.
- Games need the RetroArch hmod with its cores installed.
- Kid mode shows only the games you marked, so mark some before switching to it.
- The scanlines of games on `canoe` cannot be changed: the console draws them itself.
- NES games on RetroArch with the Nestopia core can look blurry in pixel perfect mode: the core enables its NTSC filter. Set "NTSC Filter" to off in the core options (or use FCEUmm).
- TheGamesDB uses a shared default key with a monthly limit that can run out; enter your own key in Network, Scraper, TheGamesDB API key.
- A DualShock 4 works in ClassicStation but not yet inside games.
- Arcade with the KMFD cores: `km_mame2003_plus` runs but heavy games like Mortal Kombat are CPU bound and the sound crackles, and `km_mame2000` crashes when the game starts (the core, not ClassicStation).

## Install or update

1. Put an SD card or USB stick with a `hakchi` folder in the console; the install needs it for the default theme.
2. Download `emulationstation_classicmini.hmod`, put it in hakchi's `user_mods` folder, select **ClassicStation** under Frontend and sync. Updating keeps the settings, favorites and the theme files you changed.
3. If hakchi reports the install as done but ClassicStation does not start, read hakchi's log: without the card or stick the install stops and hakchi still marks the module as installed. Remove it with "Remove modules" and try again.

To report a problem, send `/var/lib/hakchi/emulationstation/home/.emulationstation/es_log.txt` and, after a crash, `/var/lib/hakchi/emulationstation/crash.log`.
