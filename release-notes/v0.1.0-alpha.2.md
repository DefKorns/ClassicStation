# ES-PORT v0.1.0-alpha.2

Second alpha of the EmulationStation port for the NES and SNES Classic with hakchi. It is still meant for testers: expect rough edges.

Needs the RetroArch (S)NESCE hmod **v1.22.2-beta.13 or newer** for games that run on RetroArch. Older builds start the games, but a frame or the 4:3 and pixel perfect modes come out off-centre.

## What's new

- **Video mode and bezel screen** (Start, Display, Video mode and bezel): 4:3, pixel perfect or CRT filter, a bezel list with a preview picker (A), and scanlines and smoothing switches. Games started from EmulationStation use your choice instead of a fixed 4:3.
  - SNES games on the console's own emulator (`canoe`) and games on RetroArch both follow it.
  - In CRT mode the scanlines and smoothing are part of the look, so the two switches are greyed out; in 4:3 and pixel perfect each switch adds its effect.
  - On RetroArch the bezel and the effects need bezel mode, which EmulationStation now asks for when you choose a bezel or switch an effect on. Choosing "None" clears the previous bezel.
- **Return to EmulationStation tile** for the stock menu (after a crash, or after booting with Select): add the game package from the `hakchi-app` folder and sync.
- **Select at boot** keeps the stock UI for that session.
- **Home combo** (Select+Down, held for about a second, leaves a game) can be switched on or off in EmulationStation (Controller) and in hakchi (Controller hacks, Use button combination to reset). The Controller menu now follows the order of hakchi's Controller hacks.
- **Hidden developer options**: press Select seven times in Help, About to unlock them, then switch Debug mode on or off in the Help menu. It adds a more detailed log and crash log for bug reports.
- **Favourites** keep the games that are missing from the current firmware, and the Favourites list is hidden while it is empty.
- **Cleaner menus**: options that do nothing on the console are gone (system volume and audio device, system sleep, local art and hidden files, and the like), the theme options row only shows when the theme has options, and the UI mode (Kiosk and Kid) is hidden until games can be marked for kids.
- **Scraper** defaults to ScreenScraper; TheGamesDB takes your own key (Network, Scraper).
- A crash when quitting after using the scraper is fixed.
- **Settings and Start prompts** on the home screen and game lists, and a fix for a crash when reloading with an empty game list (thanks to viral_dna, DNA64).
- **DualShock 4 over USB** has an input config. It works on kernels that expose the pad as an input device.
- The scraper's backup stays on the SD card.
- Native NES games on `kachikachi` start without the RetroArch-only options that made them exit.

## Known issues

- No video playback.
- The first boot builds the library, which takes a while on large collections.
- The interface slows down while the scraper runs.
- The NES Classic and the Famicom firmware have been tested much less than the SNES Classic.
- Games need the RetroArch hmod with its cores installed.
- The scanlines of games on `canoe` cannot be changed: the console draws them itself.
- NES games on RetroArch with the Nestopia core can look blurry in pixel perfect mode: the core enables its NTSC filter. Set "NTSC Filter" to off in the core options (or use FCEUmm).
- TheGamesDB uses a shared default key with a monthly limit that can run out; enter your own key in Network, Scraper, TheGamesDB API key.
- A DualShock 4 works in EmulationStation but not yet inside games.

## Install or update

1. Put an SD card or USB stick with a `hakchi` folder in the console; the install needs it for the default theme.
2. Download `emulationstation_classicmini.hmod`, put it in hakchi's `user_mods` folder, select **EmulationStation** under Frontend and sync. Updating keeps the settings, favourites and the theme files you changed.
3. If hakchi reports the install as done but EmulationStation does not start, read hakchi's log: without the card or stick the install stops and hakchi still marks the module as installed. Remove it with "Remove modules" and try again.

To report a problem, send `/var/lib/hakchi/emulationstation/home/.emulationstation/es_log.txt` and, after a crash, `/var/lib/hakchi/emulationstation/crash.log`.
